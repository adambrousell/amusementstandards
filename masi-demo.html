Behavioral Anomaly Detection · 3 Patterns
SPEED FLAG
Checklist completed in 34 seconds — peer average is 4.1 minutes. If an operator consistently finishes a 22-item inspection faster than anyone can physically read it, the inspection didn't happen.
ZERO-VARIANCE FLAG
14 consecutive days with 100% PASS on every item. Statistically improbable on a 22-item checklist across real-world conditions. When everything is always fine, nothing is being checked.
CLUSTERING FLAG
3 checklists submitted within 90 seconds, coinciding with supervisor arrival. Batch-completion before the boss shows up. The timestamp pattern itself is evidence of fabricated compliance.
Manager Streak + Park Health Index
Consecutive shifts with complete handoffs, no missed inspections, all CARs addressed. 7/14/21-day streak badges show in handoff documents. Park Health Index (RIDE Score 35% + Inspection 25% + CACR 25% + Rotation 15%) gives each shift a single competitive daily number.

Audit Amendment Request · Record Integrity

Corrections Without
Compromising the Record.

When an operator makes an error on an audit checklist — pressed FAIL instead of PASS, selected the wrong item, entered an incorrect reading — the original record must never be silently overwritten. The Audit Amendment Request creates a linked correction record while preserving the complete original. Insurers see both. The audit trail is immutable.

Why This Matters for Loss Control
In a post-incident review, the question is always: was the inspection actually performed, or was it documented after the fact? Most systems allow records to be quietly edited — making it impossible to distinguish a legitimate correction from a cover-up. AS 360's amendment system creates a forensic-grade audit trail: every original entry is sealed, every correction is geo-verified and timestamped independently, and every approval has a named supervisor with a 4-hour window. If amendments spike — that pattern itself is a finding.
Amendment Flow · 6-Step Chain of Custody
01
Operator Identifies Error
Operator realizes a checklist answer was entered incorrectly. Opens amendment form on their phone — same device, same session. Three fields: which item, what was entered, what it should be.
02
Geo-Fence + Device Verification
GPS coordinates are captured at submission. The system verifies the operator is within the ride's defined geo-fence. Device fingerprint confirms the same phone used for the original audit. Amendment from a different location or device is flagged automatically.
03
Photo Evidence Required
Operator takes a timestamped photo of the item in question — the gauge reading, the restraint position, the inspection point. Photo is embedded in the amendment record with EXIF data preserved.
04
Original Record Sealed
The original audit entry is permanently locked. It cannot be edited, overwritten, or deleted — by anyone, at any access tier. The amendment creates a new linked record; both remain visible side by side.
05
Supervisor Approval · 4-Hour Window
Amendment routes to the shift supervisor — not the operations manager. This is a clerical correction, not a safety decision. Supervisor has 4 hours to approve or deny. If denied, original stands. One escalation attempt allowed.
06
Pattern Detection
5+ amendment requests in 30 days from a single operator auto-flags a training gap or possible gaming pattern. The amendment frequency itself becomes an Integrity pillar input — not just the corrections.
