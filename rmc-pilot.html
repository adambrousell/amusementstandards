How Multi-Ride Verification Works

If a park runs both an RMC coaster and a Larson Fireball, the verified lead operator completes modules for every RMC/Larson ride at their site. Base verification is $350/person/year for the first ride type. Each additional ride type at the same site adds $250/year — so a park running an I-Box coaster, a Fireball, and a Tilt-A-Whirl pays $350 + $250 + $250 = $850/year for that operator. One person, one completion record, all rides covered.

Global Footprint

International Installations

RMC has operating coasters in Mexico, Europe (Netherlands, Sweden, Poland, Germany), and Japan. Larson rides operate on every continent. The verification program is built for domestic rollout first, with international adaptation built into the roadmap.

Regulatory Adaptation

The pilot and initial rollout are built against ASTM F770-19 and OSHA 29 CFR 1910.147, which are the US standard. International installations operate under different regulatory frameworks — EN 13814 in Europe, local standards in Japan and Mexico. AS can adapt verification courses for international regulatory alignment on a per-region basis once the domestic program is established. Course content (ride systems, restraint verification, emergency procedures) is universal — only the regulatory documentation layer changes. Recommend: prove the model domestically, then extend to Vekoma-distributed international installations in Phase 2.
