Sample R code — heatmap generation
# Load and clean incident data
library(tidyverse); library(readxl); library(viridis)

incidents <- read_excel("incident_log.xlsx") |>
  mutate(
    month = floor_date(date, "month"),
    ride = str_to_title(str_trim(attraction_name))
  )

# Aggregate by ride x month, fill zeros
heat_data <- incidents |>
  count(ride, month) |>
  complete(ride, month, fill = list(n = 0))

# Build heatmap — rides ordered by total incident count
ggplot(heat_data, aes(x = month, y = fct_reorder(ride, n), fill = n)) +
  geom_tile(color = "white", linewidth = 0.4) +
  scale_fill_viridis(option = "magma", direction = -1) +
  scale_x_date(date_labels = "%b '%y", date_breaks = "2 months") +
  labs(title = "Incident Frequency by Attraction", x = NULL, y = NULL, fill = "Incidents") +
  theme_minimal(base_size = 11)

ggsave("heatmap.png", dpi = 300, width = 12, height = 6)

Root Cause Pattern Analysis · 4 Key Findings
1
Shift-Change Window is Your Highest-Risk Period
71% of Drop Tower incidents and 58% of Spinning Coaster incidents occur within 45 minutes of a shift change (6–8am and 2–4pm). This is a handoff protocol failure, not a staffing volume issue. The fix is a structured pre-operation checklist signed by the incoming operator before guests are loaded.
2
Summer Surge Compounds Documentation Failures
Documentation quality drops from 74/100 in April to 41/100 in July — directly correlated with seasonal staffing increases. New seasonal hires are not completing incident reports fully. Incident documentation needs to be a standalone module in onboarding, not a footnote in the general safety brief.
3
Drop Tower SOP Has a Specific Compliance Gap
Height and weight restriction enforcement is inconsistently applied. 4 of 6 critical incidents reference a failure to enforce restrictions — but the SOP language puts discretion on the operator rather than defining a mandatory step. This needs a SOP rewrite, not more training on the existing document.
4
Incident Under-Classification is Masking True Severity Profile
An estimated 18–22 incidents classified as "minor" show descriptors consistent with recordable or reportable events. This is both a compliance exposure and an insurance risk — under-classified incidents that later result in claims can create coverage disputes. A classification audit is recommended before your next renewal.
Prioritized Recommendations
1 — Revise Drop Tower SOP and require dual sign-off at shift changeCritical
Eliminate operator discretion from restriction enforcement. Mandatory pre-operation checklist signed by both outgoing and incoming operator before guests are loaded. Target implementation: 2 weeks.
2 — Rebuild seasonal onboarding with incident documentation as a standalone moduleCritical
New hires need to complete and pass a documentation assessment before being cleared to operate independently. This directly addresses the summer quality collapse.
3 — Conduct a retroactive incident classification auditHigh
Review the 18–22 potentially under-classified incidents with your legal and insurance contacts before your next renewal. Getting ahead of this is far better than having it surface during a claim.
4 — Implement ride-specific operator re-certification for Drop Tower and Spinning CoasterHigh
Both attractions show incident rates 2–3× the park average with operator error as the dominant cause. Annual generic certification is not sufficient.
5 — Add maintenance log review to Go-Karts pre-operation checklistStandard
The May brake failure was preceded by a 12-day maintenance log gap. Requiring the operator to confirm the log is current before opening is a simple fix with meaningful risk reduction.
