# Amusement Standards Website - Service Pages

This package contains 6 complete, production-ready service pages for amusementstandards.com.

## Contents

```
/assets/
  - styles.css (shared stylesheet)
  - scripts.js (shared JavaScript)
  
/services/
  - training-programs.html
  - operational-standards.html
  - compliance-regulatory-support.html
  - waiver-policy-documentation.html
  - insurance-risk-reduction.html
  - ongoing-managed-services.html
```

## Features

✅ Fully responsive design (mobile, tablet, desktop)
✅ Professional, modern aesthetics  
✅ Sticky navigation and CTAs
✅ SEO-optimized with meta tags
✅ Smooth scroll animations
✅ Conversion-focused layouts
✅ Cross-browser compatible

## Installation

1. Upload all files to your web server maintaining the directory structure
2. Update the header logo link in each HTML file to point to your actual homepage
3. Update contact information and links as needed
4. Customize color scheme in `assets/styles.css` if desired (see CSS variables at top)

## Customization

### Colors
Edit CSS variables in `assets/styles.css`:
- --primary: Main brand color
- --secondary: Accent/CTA color  
- --success: Success/check marks
- etc.

### Content
Each HTML file contains structured, SEO-friendly content ready for your CMS.

### Forms
Update form actions to point to your contact form processor or CRM.
