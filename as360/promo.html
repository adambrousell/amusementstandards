THE THREE CORE MODULES
Run the park. Not paperwork.
Three interconnected operational modules that your management, dispatch, and ride operations teams use every shift. Real-time data flows between them — OpsScan feeds operator position data into both MGR and OPD, LensIQ feeds independent throughput into the MGR dashboard, and VoxIntel feeds radio intelligence into both command and dispatch views.

DATA ACQUISITION LAYER
Three independent signals. One defensible score.
AS 360 ingests data from three independent sources that cannot be gamed simultaneously — plus a fourth aggregation layer that ingests data from platforms your park already runs. When signals agree, confidence is high. When they diverge, that gap is the finding.
Layer 2 · Field
📱
OpsScan
QR-based operator position scan-in at every ride touchpoint. Voice incident reporting, AI anomaly detection, rotation intelligence, and auto CAR generation. 90-second interaction. Full shift data.
  • Position QR scan-in — Load, Control, Unload, Queue
  • Ops Panel dual sign-off — Maintenance + Operations required
  • Voice-to-incident — Whisper + Claude AI pipeline
  • Behavioral anomaly detection — nightly AI batch
  • Dynamic rotation reminders — heat, OLI, CAR-aware
  • Works on any smartphone over 4G — no WiFi, no app
View OpsScan →
Layer 3 · Visual
👁️
LensIQ
Computer vision throughput tracking using your existing cameras. No new hardware. Claude Vision counts guests per cycle, calculates TPH, and flags anomalies — operator-independent data.
  • Integrates with existing CCTV — Verkada, Hikvision, RTSP
  • Guest headcount per cycle — 95%+ accuracy at load platforms
  • Live TPH — independent of operator self-reporting
  • Operator presence check — passive safety audit from camera
  • Throughput anomaly detection — silent slowdowns flagged
  • Zero video storage — structured count data only
View LensIQ →
Layer 1 · Passive
📡
VoxIntel
Passive RF monitoring of all venue radio channels. Real-time transcription, NLP event classification, ride-down detection, step-on collision detection — no operator involvement required.
  • All-channel radio capture — RTL-SDR hardware
  • Whisper transcription + Claude NLP classification
  • Ride-down detection — feeds OOS board automatically
  • Step-on collision detection — dispatcher safety alert
  • Channel congestion scoring — communication risk metric
  • Feeds MGR command dashboard + OPD live view
View VoxIntel →
Aggregation Layer
🔗
3rd Party Ingestion
AS 360 ingests operational data from platforms your park already runs. Keep your existing system. AS 360 sits on top and scores it — turning your existing tools into RIDE Score inputs.
  • Mobaro connector — inspections, downtime, maintenance
  • CommandCentr connector — ride checks, throughput, incidents
  • 24/7 Software connector — work orders, guard tours
  • State inspection databases — public compliance records
  • Ellis EAVS alert feed — aquatic AI events → SPLASH Score
  • Field normalization → 0–100 stream model → Score
